# Code of Conduct

This project expects respectful, constructive participation.

Do not harass, threaten, insult, or discriminate against other contributors.

Assume good intent, keep technical disagreements focused on the work, and help maintain a welcoming environment for new contributors.

Project maintainers may moderate issues, pull requests, discussions, or other project spaces to uphold these expectations.

To report conduct concerns, contact the project maintainers privately.
